# FlyGACA C172N Digital Twin — Phase 6

## التشغيل
1. فك ZIP في مجلد واحد.
2. افتح Terminal داخل المجلد وشغّل `python -m http.server 8000`.
3. افتح `http://localhost:8000/FlyGACA_C172N_Phase6_Viewer.html`.
4. يلزم الإنترنت لتحميل Three.js من CDN. لا يكفي فتح ملف HTML عبر `file://` في كثير من المتصفحات بسبب قيود تحميل GLB.

## الملفات
- `C172N_Phase6_Animated_Parts.glb`: 224 جزءًا قابلًا للتعديل، مجموعات Engine, Ignition, Oil, Fuel, Electrical, Panel.
- `C172N_Airframe_Approx.glb`: نسخة تقريبية للهيكل السابق، منفصلة عن عرض الأنظمة.
- `FlyGACA_C172N_Phase6_Viewer.html`: عارض تفاعلي وتحديد أجزاء وعزلها وتفكيكها وحركة تعليمية للقطع ومحرك حالات مبسط.
- `phase6_manifest.json`: بيانات المشروع ومعلومات التحقق ومخرجات الدروس.

## حدود التوثيق
- 172N / 1979 تجهيزات المصنع: **اختيار مرجعي للمشروع**، وليس إثباتًا لمواصفات طائرة بعينها.
- المحرك المرجعي Lycoming O-320-H2AD: يتطلب المطابقة مع POH/AFM ومواصفات المحرك.
- هندسة المجسم والمكابس والصمامات ليست CAD أو كينماتيكا دقيقة، ولا تتضمن سلسلة حركة صحيحة.
- محاكاة RPM والوقود والكهرباء وأعطال Pitot-Static مبسطة ولا تحاكي الأنظمة الحقيقية بدقة.
- لا يتم محاكاة إجراءات التشغيل أو القيم التشغيلية المعتمدة؛ لا تستخدم المواد لاتخاذ قرارات طيران أو صيانة.
- لم يختبر HTML في متصفح فعلي؛ قد تحتاج إلى تصحيح توافق المكتبات أو العرض.
- لم يجر نشر أو تعديل FlyGACA.com أو مستودعات GitHub.

## للتطوير اللاحق
إضافة مصادر POH/AFM مع صفحات دقيقة بعد مراجعة النسخة الأصلية، ثم إعادة نمذجة الهندسة وفق IPC، ومحرك محاكاة ديناميكي موثق، واختبارات Playwright، ودمج رسمي في FlyGACA.
