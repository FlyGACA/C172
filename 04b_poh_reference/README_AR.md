# FlyGACA C172N — POH Reference Applied

**المصدر:** دليل Cessna 172N موديل 1979 الصادر عن Cessna بتاريخ 1 يوليو 1978.

الرابط: https://teensinflight.org/wp-content/uploads/13F-C-172N-1979-POH.pdf

**التطبيق الفعلي:** إضافة ملف بيانات مرجعية مع مصدر كل قيمة ورقم الصفحة، وواجهة HTML تعليمية تعرض بيانات المحرك والوقود والوزن وأبعاد الطائرة المستندة إلى الدليل. ملفات GLB هي النسخ السابقة دون تغيير هندسي، لأن POH ليس مخطط CAD ولا يمكن الادعاء بأنه يجعل المجسم مطابقًا للطائرة.

**المحرك:** O-320-H2AD، 160 BHP عند 2700 RPM؛ 4 أسطوانات متقابلة، تبريد هوائي، كربراتير.
**الوقود:** قياسي 43 جالون إجمالي / 40 قابل للاستخدام؛ مدى طويل 54/50.
**الوزن:** 2300 رطل حد الإقلاع للفئة العادية.

**مهم:** هذا مرجع 1979، بينما مصدر NTSB الذي عُثر عليه خاص بـ 1978 ويعرض مقتطفًا من القسم الرابع. قبل اعتماد إجراءات تشغيل أو قيود لطائرة معينة، يجب التحقق من الرقم التسلسلي ونسخة POH/AFM والملحقات والتعديلات.
