# FlyGACA Cessna 172 Classic Analog — V2
نموذج تدريبي أولي قابل للتحرير، وليس نسخة هندسية معتمدة من Cessna.

## الملفات
- Cessna_172_Classic_Analog_V2.glb — مجسم GLB متعدد الأجزاء
- FlyGACA_Interactive_Viewer.html — واجهة عرض تفاعلية (تحتاج إنترنت لمكتبات Three.js)
- Build_Editable_Cessna172.py — سكربت إنشاء النسخة الأساسية
- reference_photos/ — الصور المرجعية

## التشغيل
افتح ملف HTML في متصفح حديث، ثم اختر ملف GLB باستخدام زر اختيار الملف.
قد تحتاج إلى خادم محلي إذا منع المتصفح تشغيل JavaScript modules من ملف محلي:
`python -m http.server 8000` ثم افتح http://localhost:8000/FlyGACA_Interactive_Viewer.html

## حدود النموذج
المجسم مبني من أشكال هندسية تقريبية، وليس مسحًا فوتوغرامتريًا أو CAD مطابقًا.
حركة أسطح التحكم توضيحية ولا تتضمن مفاصل هندسية دقيقة أو فيزياء طيران.
العدادات ثابتة وغير مرتبطة ببيانات طيران. يُرجى عدم استخدامه للتدريب الإجرائي المعتمد.
